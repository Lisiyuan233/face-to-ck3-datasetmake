# 真人照片到 CK3 训练域：生图转换模板

## 参考图

`ck3_training_grayscale_reference.png` 是结构与构图参考，不是身份参考。它根据训练集
固定条件制作：左侧正面、右侧严格 90° 右侧面、同一身份、光头、无表情、暗色纹理
背景、统一头部尺度。

推荐给生图模型提供三张输入：

1. 真人正面照：身份、五官、肤色和年龄参考。
2. 真人右侧面照：鼻梁、嘴唇、下巴、后脑和颈部轮廓参考。
3. 灰度模板：只参考姿态、构图、尺度、背景和双视图布局。

若模型允许增加第四张参考图，可以从训练集选一张原始组合图作为材质和光照参考，
但不要让模型复制该训练角色的脸。

## 可直接粘贴的转换提示词

```text
任务：把输入真人照片转换成与参考训练集同域的半写实 3D 游戏角色渲染组合图，供面部参数模型推理使用。

输入图角色：
- 图 1：真人正面身份参考。保留其稳定身份特征、年龄、脸型、五官比例和肤色。
- 图 2：同一个人的右侧面身份参考。保留真实的鼻梁、嘴唇、下巴、后脑和颈部轮廓。
- 图 3：灰度双视图结构模板。只复制它的画布比例、相机角度、头部尺度、位置和背景布局；不要复制模板人物的脸，也不要把最终结果变成灰色。

输出一个 3:2 横向画布中的同一人物双视图：
- 左半边是严格正面、头部居中、双眼平视镜头；
- 右半边是严格 90° 右侧面，鼻尖朝画面右侧；
- 两个头属于完全相同的身份、年龄、脸型和五官比例；
- 两个头大小一致，眼睛高度接近，头顶留少量边距，颈部和少量肩部延伸到画面底部；
- 使用接近正交或长焦的人像相机效果，禁止广角透视和三分之四侧脸。

人物处理：完全去除头发、发际线、胡须和可见毛发，但必须保持原始颅骨、下颌和面部身份；中性放松表情，嘴自然闭合，双眼正常睁开；移除眼镜、耳环、帽子、妆容和其他遮挡物；只保留简单无纹理的浅色衣领或肩部底座。

渲染域：半写实 CK3 风格的 3D 游戏角色渲染，保留真实肤色和年龄纹理；皮肤有轻微毛孔与自然粗糙度，但不要照片级毛发，不要磨皮，不要美化。深蓝黑色低细节斑驳背景。固定柔和棚拍式游戏灯光：左前上方柔和主光，右后上方很弱的冷色轮廓光；鼻、眉弓、颧骨、下颌和颈部轮廓清晰，避免戏剧性阴影。

最高优先级：身份一致 > 正面/90° 侧面几何准确 > 头部尺度和裁剪一致 > 训练集渲染风格。最终输出为彩色 PNG，推荐 1536×1024；不要添加文字、标签、分隔线、边框、标尺、logo 或水印。
```

## Negative prompt（支持时使用）

```text
hair, hairline, beard, moustache, stubble, glasses, jewelry, hat, makeup,
smile, open mouth, visible teeth, exaggerated expression, head tilt,
three-quarter view, left-facing profile, perspective distortion, wide-angle,
different identities between panels, different ages between panels,
different skin tones between panels, cropped crown, cropped chin,
photographic background, shallow depth of field, cinematic lighting,
beauty retouching, anime, illustration, text, labels, divider, border, watermark
```

## 建议工作流

1. 尽量同时拍正面和右侧面：中性表情、平视、均匀光线、无遮挡。
2. 用上面的提示词和灰度模板生成 `1536×1024` 彩色组合图。
3. 检查右图确实是鼻尖朝右的严格侧面，并确认两张脸是同一个人。
4. 在推理 GUI 中选择“CK3 采集组合截图（自动裁剪）”输入生成图。
5. 若只能提供一张正面照，侧面会由生图模型猜测，鼻梁、下巴、后脑等字段不可靠。

当前训练集是男性角色数据；女性真人即使完成域转换，也仍存在训练分布之外的问题。
