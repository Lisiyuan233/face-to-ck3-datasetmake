# 256ram 服务器虚拟机多开数据集采集可行性研究

研究时间：2026-09-01 03:45 UTC | 结论：**可行**。建议 1 卡 1 VM 起步（先给 NVLink 对端空置的 83:00.0），验证后扩到最多 3 实例。

## 一、采集负载特征（决定 VM 需求）

- 采集器 `face_to_ck3_tool.py` 是 **Windows GUI 自动化**：点击随机外貌 → 剪贴板复制 DNA（两次一致性校验）→ 低分预览帧检测渲染稳定 → 截图 → 原子写盘；另有种族自动切换。
- 每实例需要：完整 Windows 桌面 + CK3 运行 + GPU 渲染（DX11 人物 3D）+ 鼠标/剪贴板。
- **实测单实例速率**（4060Ti Windows 机器）：08-22 18:45 → 08-31 20:50 采集 84,433 样本 ≈ **9,300 样本/天（约 9.2 秒/样本）**。瓶颈在采集协议的多次校验等待，不在 GPU 算力——2080Ti 直通绰绰有余。

## 三、资源分配

- **首选直通 83:00.0**：该卡 NVLink 对端槽位空置（故障卡已拔），对宿主机多卡价值最低。
- 当前 3 卡全部被 v2 训练占用，预计 **09-01 05:40 UTC（北京 13:40）训练结束**后可释放。
- 若之后还要训练/llama-server：3 卡分配制，例如 2 VM + 1 宿主。
- vCPU 每 VM 6~8 个（3 VM 共 24，宿主留 16）；网络 NAT 即可（Steam + 飞书通知）。

## 四、落地步骤（预计半天~一天）

1. 安装虚拟化栈（上面 apt 命令），把 li 加入 libvirt 组；
2. 建 Windows 10/11 VM：OVMF(UEFI) + virtio 磁盘/网卡 + 83:00.0 直通 + SPICE 显示；装 virtio-win 驱动；
3. guest 内装 Steam、CK3、Python + 本 repo；
4. **每实例一次性标定**按钮坐标（collection_settings.json 是绝对屏幕坐标，VM 分辨率需与标定时一致）；
5. 采集器 guest 内自启（宿主无头挂着 SPICE/VNC 会话即可，不要用断开的 RDP——锁屏会破坏截图）；
6. 先采 10~20 个样本人工核验（DATA_COLLECTION.md 流程），再放量。

## 六、账号与合规注意

- 同一 Steam 账号不能多机同时在线：N 个并发实例需要 **N 个账号、各持一份 CK3**（离线模式不稳定，不推荐）。
- Windows 可无激活评估运行（有限制）；CK3 单机无反作弊，ToS 不禁止 VM。

## 七、风险与替代

- 风险：E5-2680 v2 单核弱，若 CK3 在 VM 内帧率过低，稳定性检测等待变长，实际速率可能低于 9.3k/天（pilot 实测定）；被直通的卡在宿主 nvidia-smi 中不可见属正常。
- 替代方案（更省资源但需开发）：CK3 可经 Proton 跑 Linux 原生进程，采集器从 pywin32 移植到 xdotool/wl-clipboard 后可多开虚拟 X 会话，免去 Windows VM 与直通；属代码改造路线。VM 路线零代码改动。

## 八、补充：一张显卡能否支撑多个实例？

直通方案下 1 卡 = 1 实例独占，但这只是方案特性而非硬件必然：

- **官方 vGPU/SR-IOV**：GeForce 不支持（需专业卡）；2080Ti 有社区 vgpu_unlock（Turing 可切分），但锁驱动版本、模拟授权、违 EULA，不推荐。
- **virtio-gpu/virgl/Venus**：Windows guest + DX11 游戏走不通（virgl 仅 OpenGL，Venus 仅 Linux guest）。
- **一个 Windows VM 多会话**：每会话独立剪贴板/桌面坐标系，恰好兼容采集器假设，一份数据盘装 N 套实例；但 Win10/11 多并发 RDP 需 Windows Server 或灰色补丁。
- **Linux + Proton 多 DISPLAY**：每 DISPLAY 独立剪贴板，一卡按显存可塞 5~6 实例，是最彻底的共享方案；需移植采集器（pywin32 → xdotool/wl-clipboard）。

**负载事实**：采集 ~9.2s/样本中大部分在等校验/渲染稳定，GPU 实际占用低——共享一卡在算力上成立，瓶颈是工程稳健性而非算力。建议：pilot 用直通（唯一零改动且稳定的路径）；若将来长期大规模采集（日采 5 万+）再评估 Proton 多 DISPLAY 移植，一卡可顶三卡。
